# Презентация (6 слайдов)

1. **Проблема и решение.** Фишинговые ссылки в мессенджерах и дипфейки в рекламе/«звонках родственников».
   Qorgau AI: проверь ссылку, QR или медиа до доверия. Без регистрации. Чего *не* делаем: фоновая защита, блокировка сайтов.
2. **Архитектура.** Схема из README: Expo-приложение (SQLite-история, QR на устройстве) → FastAPI (URL-анализ, SSRF-защищённый
   сетевой модуль, детектор, агент). Ключи только на сервере. Скриншоты: Главная и Результат.
3. **Неделя 8 — классический ML.** 243 239 URL из двух CC BY 4.0 датасетов, разбиение по доменам (пересечение 0),
   39 признаков. Таблица: majority F1 0 · правила 0.634 · LR 0.755 · **RF 0.809** (P 0.905, R 0.732). Матрица ошибок RF.
   Кросс-датасет: F1 0.69 — урок о переносе и артефактах датасета (почему убрали схему и `www`).
4. **Неделя 9 — нейросети.** ViT-B/16 (Apache-2.0), что реализовано у нас: препроцессинг, лицо → кроп, батч-inference,
   медиана по ≤ 16 кадрам, «Недостаточно данных», изоляция процесса. Честный результат: DeepFakeFace, ROC-AUC 0.49 —
   модель не обобщается; абляция без кропа — 0.51. Что сделали в UI из-за этого.
5. **Неделя 1 — агент.** Диаграмма состояний OBSERVE → … → DONE, реестр инструментов, fallback при недоступной модели,
   повтор без сети, журнал шагов на экране. Защита от prompt injection: текст — данные, LLM получает только обезличенные факты.
6. **Безопасность, тестирование, ограничения.** SSRF: DNS pinning, проверка каждого редиректа, лимиты. 123 backend-теста +
   12 mobile-тестов, сборка бандлов iOS/Android. Не сделано: запуск на устройствах, проверка с реальными ключами LLM/Safe
   Browsing, вычитка казахской локализации. Дальше: лучшая модель дипфейков, расширение списка брендов, HTTPS-деплой.
