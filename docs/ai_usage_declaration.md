* Нашёл и скачал публичные датасеты и модель, проверил их лицензии по карточкам/страницам источников.
* Запустил обучение классификатора, тесты и оценку детектора; все метрики в отчётах — результат этих запусков, а не
  сгенерированный текст.

## AI внутри продукта
* Классификатор URL (scikit-learn Random Forest) — обучен в проекте.
* Детектор дипфейков — сторонняя предобученная модель `prithivMLmods/Deep-Fake-Detector-v2-Model` (Apache-2.0), локальный inference.
* Опционально: Claude через Anthropic API для перефразирования объяснений (только при наличии ключа на сервере; по
  умолчанию выключено). Основные проверки работают без платных API.
