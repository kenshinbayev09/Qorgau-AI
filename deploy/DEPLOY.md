# Развёртывание сервера на Hugging Face Spaces (бесплатно)

Сервер будет работать в интернете с адресом `https://...hf.space`, без ноутбука.

> Что сделать вам: регистрация и вход в аккаунт, создание токена, загрузка файлов. Это требует вашего аккаунта, поэтому автоматически я это сделать не могу.

## Шаг 1. Аккаунт и Space

1. Зарегистрируйтесь на https://huggingface.co.
2. Откройте https://huggingface.co/new-space и заполните:
   * **Space name:** `qorgau-api`
   * **SDK:** **Docker** → template *Blank*
   * **Hardware:** **CPU basic (free)**
   * **Visibility:** Public (нужно, чтобы телефон мог открыть адрес)
3. Нажмите **Create Space**.

## Шаг 2. Токен доступа

https://huggingface.co/settings/tokens → **Create new token** → тип **Write**. Скопируйте токен и никому не показывайте.

## Шаг 3. Подготовить файлы (на ноутбуке)

В PowerShell в папке проекта (`scratch-2026-11-08-d56f80`):

```bash
..\.venv\Scripts\python deploy\make_space.py --dest ..\qorgau-space
```

Папка `..\qorgau-space` появится рядом с проектом.

## Шаг 4. Загрузить в Space

Нужен Git и Git LFS (файл модели большой). Выполните:

```bash
git lfs install
```

```bash
git clone https://USER:ТОКЕН@huggingface.co/spaces/USER/qorgau-api
```

Замените `USER` на ваш логин Hugging Face, `ТОКЕН` — на токен из шага 2. Потом скопируйте содержимое `..\qorgau-space` в папку `qorgau-api` (всё, включая `backend`, `ml` и `Dockerfile`) и выполните:

```bash
cd qorgau-api
```

```bash
git add .
```

```bash
git commit -m "Initial API"
```

```bash
git push
```

## Шаг 5. Дождаться сборки

На странице Space появится лог сборки. Она может занять 10–20 минут: устанавливается PyTorch и скачиваются веса. Когда статус станет **Running**, проверьте в браузере:

```
https://USER-qorgau-api.hf.space/api/v1/health
```

Должен появиться текст с `"status":"ok"`.

## Шаг 6. Подключить приложение

Пока приложение открывается через Expo Go с ноутбука, в **Settings → Адрес сервера API** впишите адрес `https://USER-qorgau-api.hf.space` (без `/api/...`) и нажмите **Проверить соединение**. Сервер будет работать уже без ноутбука.

## Важно

* **Ноутбук всё ещё нужен для Expo Go:** приложение загружается с сервера разработки на ноутбуке. Чтобы телефон работал полностью без ноутбука, нужна собственная сборка приложения (см. ниже).
* **Сон сервера:** бесплатный Space засыпает без запросов. Первый запрос после паузы может идти минуту.
* **Ключи** (Safe Browsing, Claude) задаются в настройках Space (*Settings → Variables and secrets*), а не в коде.

## Собственная сборка приложения (без ноутбука)

* **Android:** APK через EAS Build (профиль `preview`). Платного аккаунта не требует, бесплатные сборки ограничены по количеству.
* **iPhone:** установка собственной сборки возможна только с платным аккаунтом **Apple Developer** (около $99 в год). Без него на iPhone работает только Expo Go, который требует запущенного сервера разработки.

Если решите делать собственную сборку, скажите, и я подготовлю конфигурацию EAS. Команды, которые будете выполнять вы, требуют входа в ваш аккаунт Expo.
